# Lista de Exercícios – Isolation Forest

Cada exercício está em sua própria pasta (`ex1` a `ex8`), com o script `.py`, o `README.md` com as respostas e, quando pedido, o gráfico gerado (`grafico_exN.png`).

## Como executar

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt

python ex1/ex1.py
```

Os exercícios 7 e 8 leem os arquivos `sensores_ambientais.csv` e `vendas_ecommerce.csv` desta pasta. Os scripts encontram os arquivos sozinhos, então podem ser executados de qualquer diretório.
